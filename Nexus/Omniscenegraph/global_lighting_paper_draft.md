## 1. 动机

在车载动态场景中，几何、材质和照明往往同时变化。仅依赖每个高斯点的局部外观参数，即便引入球谐方向编码，也主要是在建模“视角相关颜色”，而不是场景级照明的传播规律。这种做法有两个明显局限。

第一，局部颜色参数容易把光照变化吸收进纹理本身，导致同一物体在不同时间或不同相机下出现不一致的外观。第二，动态场景中存在明显的曝光漂移、天空散射、车灯和路面反射等全局项，它们不是单个点的属性，而是与时间、相机和场景整体状态相关的照明信号。

因此，我们将照明从几何和材质中显式独立出来，设计一个轻量的全局光照模块。它不是传统意义上的离线全局光照求解，而是一个可学习的场景级照明函数，用来生成随时间和相机变化的球谐照明系数，再与局部材质响应耦合，从而实现更稳定的外观分解。

## 2. 方法

### 2.1 总体表示

对每个高斯点，我们保留几何与外观的基础参数，并额外引入材质和法线分量：

- 位置 `x_i`
- 尺度 `s_i`
- 旋转 `q_i`
- 不透明度 `\alpha_i`
- 漫反射反照率 `a_i`
- 法线 `n_i`
- 粗糙度 `r_i`
- 金属度 `m_i`
- 一组各向异性高光分量 `\{(\omega_{ij}, \beta_{ij}, d_{ij})\}_{j=1}^{J}`

其中 `J=4` 是实现中使用的高光瓣数。对应代码中分别是 `_features_dc`、`_normals`、`_roughness`、`_metallic`、`_asg_amplitude`、`_asg_sharpness` 和 `_asg_dir`。

与其把所有外观都塞进一个黑盒颜色网络，不如把辐射分解成“材料项 + 照明项”，让每个分量承担更明确的物理意义。

### 2.2 全局光照函数

全局光照模块记为 `G_\theta`，输入为归一化时间 `t` 和相机编号 `c`：

`L(t, c) = G_\theta(\gamma_t(t), e_c)`

其中 `\gamma_t(\cdot)` 是时间的正弦位置编码，`e_c` 是相机可学习嵌入。实现中，模块先将 `t` 经过 sinusoidal encoding，再与 `appearance embedding` 拼接，最后通过多层感知机回归一组球谐系数：

`L(t, c) \rightarrow \{ \ell_{l,m}(t,c) \} , \quad l=0,\dots,K,\; m=-l,\dots,l`

这里 `K=2`，因此输出维度为 `3 × (K+1)^2`，即三个颜色通道各自对应一组 SH 系数。

这个设计的关键点不在于“用了球谐”，而在于球谐系数不是固定环境贴图，而是由时间和相机共同驱动的动态照明表示。这样可以把曝光、光照方向偏移和场景整体亮度变化吸收到一个独立分支中，而不是污染每个高斯点的局部外观参数。

### 2.3 漫反射项

给定法线 `n_i`，全局光照模块产生的 SH 系数可写成照明函数：

`E(n_i; t, c) = \sum_{l=0}^{K}\sum_{m=-l}^{l} \ell_{l,m}(t,c)\, Y_l^m(n_i)`

其中 `Y_l^m` 是球谐基函数。为了避免负照明，我们对结果做截断：

`E^+(n_i; t, c) = \max(0, E(n_i; t, c))`

于是漫反射项为：

`L_d = a_i \odot E^+(n_i; t, c)`

这一步把场景级照明和局部反照率解耦，保证材质颜色更多地反映物体本身，而不是相机或时间引起的亮度变化。

### 2.4 各向异性镜面项

仅靠漫反射无法解释车漆、金属牌、玻璃边缘等高频高光，因此我们再引入多瓣各向异性高光近似。对第 `j` 个高光瓣，定义半程向量：

`h_{ij} = \frac{v_i + d_{ij}}{\|v_i + d_{ij}\|}`

其中 `v_i` 是视线方向，`d_{ij}` 是可学习高光方向。镜面强度定义为：

`s_{ij} = \big(\max(0, n_i^\top h_{ij})\big)^{\rho_i}`

`rho_i = \frac{10}{r_i + \varepsilon}`

于是总镜面项为：

`L_s = \sum_{j=1}^{J} \omega_{ij} \odot s_{ij}`

实现上，`roughness` 控制高光尖锐程度，`asg_amplitude` 控制不同颜色通道的高光能量，`asg_dir` 则为每个瓣提供方向基元。这个结构比单纯的 PBR 标量高光更灵活，可以表达局部非对称反射和复杂的方向性高光。

### 2.5 最终颜色

最终 HDR 颜色为：

`L_{hdr} = L_d + L_s`

随后采用压缩映射得到可渲染颜色：

`C = \frac{L_{hdr}}{1 + L_{hdr}}`

该形式在数值上稳定，也避免了极亮区域对训练造成梯度爆炸。

### 2.6 与高斯场景表示的耦合

在训练流程中，`GlobalLightingModule` 不是独立输出图像，而是先生成 `global_sh_coeffs`，再传递给背景高斯的 `compute_pbr_color()`：

`C_i = F(x_i, n_i, a_i, r_i, m_i, v_i, L(t,c))`

其中背景高斯在 `get_gaussians()` 中调用该模块，而动态节点仍可保留各自的几何和外观建模方式。也就是说，全局光照是作为一个场景级先验注入到渲染管线中，而不是替代局部表征。

## 3. 为什么它不同于“只是 PBR”

这套方法和常见 PBR 写法的区别在于三点。

第一，它不是单纯从法线、视角和材质出发做局部反射近似，而是显式建模了 `t` 与 `c` 维度上的全局照明变化。

第二，它把照明表示成低阶球谐系数，这是一种紧凑的场景级函数近似，适合动态车载序列中的缓慢光照漂移和跨相机一致性建模。

第三，它与高斯分裂、复制和剪枝机制联合优化。也就是说，照明分支并不是静态附着在纹理上，而是和场景结构一起演化。这使得模型更容易把“几何变化、材质变化、照明变化”拆开，避免把所有误差都堆到颜色项里。

## 4. 效果

从训练行为上看，引入全局光照模块后，模型在不同相机和不同时间帧之间更容易保持颜色一致性，尤其是在天空、地面反射和亮暗过渡区域。由于照明被单独参数化，背景高斯不需要用局部颜色去拟合全局光照偏移，因而更有利于稳定收敛。

从结果上看，这种结构通常带来两类收益：

- 视觉上，亮度漂移更小，跨帧闪烁减弱，反射和阴影边界更自然。
- 优化上，材质参数和照明参数的职责更清晰，减少了颜色项对几何和外观的错误补偿。

如果你在论文里需要给出实验描述，可以把这一段写成“在相同训练设置下，加入全局光照分支后，渲染结果在时序一致性和高光区域的重建质量上更稳定”。如果后续补充定量实验，建议重点报告 `PSNR`、`SSIM` 和跨帧一致性指标。

## 5. 可直接改写的论文表述

我们设计了一个场景级全局光照模块，用于显式分离动态场景中的照明变化与局部材质表征。该模块以归一化时间和相机身份为条件，通过正弦位置编码和可学习相机嵌入生成低阶球谐照明系数，并将其映射到法线方向上的漫反射辐照度。随后，结合可学习的反照率、粗糙度、金属度及各向异性高光瓣，构建由漫反射项和镜面项组成的可微反射模型。与直接使用视角相关颜色拟合不同，该方法将场景照明从高斯外观中解耦出来，使模型能够更稳健地处理跨时间、跨视角的曝光变化与全局亮度漂移，并提升复杂反射区域的重建一致性。
