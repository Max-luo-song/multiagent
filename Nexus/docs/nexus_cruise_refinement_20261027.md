# 巡航速度与风险后恢复优化（2026-10-27）

目标是改正上一版无事件时也持续慢行的偏差，同时保留切入制动、车道保持及运动一致性。模型权重和旧升级代码保持不变，E/C 的未来条件掩码仍为空；没有写入按时刻指定的 E/C 位置或速度。

## 推理改动

1. `omega_cruise.py` 增加来自当前观测速度的软巡航偏好和末段速度恢复目标，适用于所有满足条件的自由车辆。静止车辆不受“必须起步”的巡航目标约束。
2. 保留网络提案的横向软偏好，减弱绝对纵向位置对通行时间的牵制，避免慢速提案和约束修正相互强化。
3. 修复速度下界的优化梯度。前向状态仍投影为非负速度；优化时通过下界使用代理导数，避免已经停车的轨迹无法获得恢复速度的梯度。巡航目标采用沿车头的标量速度，避免零向量范数在零速处丢失恢复梯度。
4. `omega_cruise_corridor.py` 增加完整车身的车道距离场偏好。距离场来自 SDK 当前车道及相连延续车道，分辨率 0.1m。给定前车进入本车道时降低该车的车道偏好强度，保留避让自由。
5. 控制变量自身投影到随速度变化的曲率上界，避免隐藏的大曲率在前向被截断后，转向梯度为零。保留加速度、横向加速度、曲率及变化率限制。

这些是控制空间推理优化，既不是重训练后的 Nexus 权重，也不是完整车辆动力学仿真或精确 Gaussian-KL OMEGA 保证。

## 验证与保留的回归记录

- 合成检查：慢速神经提案但无风险时的巡航；切入时允许制动；前车停车并重新移动后允许恢复。命令：`../envs/nexus/bin/python -B scripts/pipeline/check_nexus_cruise_guidance.py`。通过结果保存在 `artifacts/nexus_kinematic_20261027/cruise_selfcheck.json`。
- `candidate_v2_cruise` 的真实正常 E 已恢复约 12.4m/s 的巡航，事件 E 可从约 5.8m/s 恢复至约 11.4m/s，但正常 C 的车框有 13 个检查点越出原车道，因此没有把该版本推广为通过。
- `check_nexus_corridor_regression.py` 对这个已知 C 回归进行离线优化探针，验证 E/C 完整车框都在原车道、E 仍维持巡航。探针只保存诊断 JSON，不作为新预测交付。
- 回归候选之后，最终版本 `candidate_v4_cruise_initialized` 使用当前地图车道的可行控制暖启动，重新加载官方权重执行完整 Nexus 采样。暖启动只提供优化起点，正常与事件相同，后续全部自由控制仍可改变。正式视频只能来自该次新预测，不能使用离线探针修补旧轨迹。

正式命令（目录存在时拒绝覆盖）：

```bash
../envs/nexus/bin/python -B scripts/pipeline/run_nexus_cruise_initialized_candidate.py --stage candidate_v4_cruise_initialized --seeds 0
artifacts/nexus_3dgs/venv/bin/python -B scripts/pipeline/report_nexus_cruise_candidate.py --stage candidate_v4_cruise_initialized
```

## 验收范围

继续保留有向车框、道路范围、正常原车道保持、加速度、倒行和朝向一致性的检查。新增的速度行为门槛在采样前写入协议：最终采样前，正常 E 的任一区间及末段速度门槛加强到观测基准的 85%，8 秒通行距离门槛加强到 90%，防止中途无谓慢行而只在末端补速度；事件 E 要有至少 1m/s 的额外早期降速，并在末段恢复到自车观测／给定前车参考速度较低者的 80%。

这些门槛是场景 033 的诊断基准，不是适用于红灯、停车等所有场景的速度规则。它们只决定样本是否通过本轮验证，不作为未来轨迹条件。未通过完整验收的样本保留作诊断，不获准导出下游。

新旧比较维持同一前两秒历史、同一 A 完整未来、同一背景、同一存在掩码和初始噪声。A 共用前移 2m 的编辑偏移，事件在未来 0.5–2.5s 向右切入 3m。地图参考只用当前观测和路网；97 个背景参与者记录回放与未来存在掩码是显式额外信息。真实未来速度只在上一轮原因诊断中对照使用，不用于本轮速度目标。

最终数值、原始预测散列、是否通过、视频帧数及完整报告路径见 `artifacts/nexus_kinematic_20261027/candidate_v4_cruise_initialized/` 下的 `run.json`、`report_completion.json` 和 `delivery.json`。结果只代表当前单场景、单种子，联合轨迹差异不证明严格的三车因果链。

## 最终正式采样与交付

最终版本：`candidate_v4_cruise_initialized`。地图纯追踪只初始化控制变量；正常／事件具有相同初始化，后续 E/C 全部控制仍可调整。正式输出来自完整 Nexus 采样，不来自离线探针。

正常速度验收在最终采样前加强为：任一区间和末段速度不低于观测基准的85%，通行距离不低于90%；避免仅在末端恢复掩盖中段无谓慢行。事件仍要求额外早期降速和末段恢复。
