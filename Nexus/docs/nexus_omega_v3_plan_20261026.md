# Nexus 第三轮计划：转向能力与运动一致性

用户要求先规划再优化。正式根目录：`/inspire/hdd3/project/intelligent-driving-agent/public/workspace/hzy/`。本轮不训练模型、不更新 v9 资产、不覆盖历史结果、不改变公交倒车事件。

## 问题与基线

冻结 `artifacts/nexus_omega_v2/order_candidate_v1` 为本轮对照。开发场景、条件、初始噪声、种子 0/1/2 及显示种子 0 均保持。事件与正常组配对，公交第 3–6 秒的倒车/停止为既有受控条件。

基线事件组：三种子密集全车辆重叠计数 0，加速度超限点 4；正常组密集重叠计数合计 2。种子 0 事件自车曾后退约 0.9 米，朝向偏转不足 1 度；上一轮左绕行为不能只凭碰撞指标被替代。既有背景记录未来与存在 mask 的信息条件保持，不能称为纯历史预测。

## 顺序与预先声明的判断方法

1. **单因素定位**：运行 `heading_unlocked_probe`，只取消 `--lock-predicted-heading`，其余配置与基线完全相同。先跑种子 0 的正常/事件对照，确认是否恢复转向以及是否产生旋转车框或横向滑动；若有收益再冻结到另外两个种子。先观察，不预先断言朝向开关是唯一原因。
2. **针对性修正**：根据上述证据，在可选分支内加入由 XY 差分速度计算的非完整约束（沿车体横向速度）、朝前运动/倒车惩罚，并核对速度输出通道。只约束自由未来；历史和公交条件精确。先做无此项/有此项对照；不同时任意改变碰撞、道路、KL 和跟随权重。公交的指定倒车条件不能受到自车朝前偏好的篡改。
3. **行为验收**：允许等待与绕行，不硬编码“必须左转”，不通过指定自车未来轨迹制造成功。若局部优化无法探索绕行，再独立设计分支候选与路线约束；地图可行驶区域不能证明逆行、变道或左转合法。
4. **冻结与扩场景**：先核对三个种子的正常/事件六组原始轨迹，再对最终候选渲染固定 v9 的 80 个实际曝光时刻。上述验收未满足时不扩场景、不提升为默认。通过后再接入 3–5 个独立场景，先重做身份绑定和背景来源审计。

## 接受标准与记录项

- 碰撞：独立 NumPy SAT、固定观测尺寸、0.1 秒以及实际相机时刻分别检查；事件组三种子不能超过基线的 0，正常组不得增加现有残余。额外目标为消除正常组残余。
- 道路：真实地图中心及完整车框分别检查，不能以中心合规替代车框合规。
- 运动：位置差分的加速度 >5 m/s² 点不超过事件基线 4；同时记录 jerk、速度头残差、沿车体横向速度、倒车累计距离和最大倒车速度。方向指标只在位置差分速度 >0.5 m/s 时计算。不得以转动车头而横向滑移制造避让。
- 行为：报告前向进展、左/右横移、朝向偏转和转向发生时刻，不将更大的左移或更大的进展本身视为更优。没有倒车意图的当前测试中，自车累计后退 >0.2 米单列为行为失败。
- 完整性：给定条件逐值精确、自由未来输入清零、自车未来自由、每步逐车 KL 不超预算、官方权重与 v9 资产不变；失败和拒绝求解全部保留。
- 成本：报告单样本耗时，不宣称实时。所有配置、核心源码快照、输入/输出哈希、数值审计和视频保存到 `hzy/`。

输出目录：代码与实验在 `nexus_repro/Nexus/artifacts/nexus_omega_v3/`；报告在 `report/nexus_omega_v3_20261026/`；本轮交接在 `others/`。本计划的后续阶段有验收依赖，未通过时须明确列为尚未完成。

## 第一阶段之后的预定修正

新增可选 `--ego-motion-weight 100`，仅在 `structural` 分支启用。组合项为 `横向XY差分速度² + 10×负向车身速度² + 0.2×XY速度与速度头残差²`，只统计自车自由未来，不干预公交指定倒车。与开放朝向的对照只相差这个组合项；不能据此分别推断三个子项的贡献。不添加强制左转目标或进度奖励，不改碰撞/道路/跟随/KL 权重。零权重保持旧采样行为。

新增 6 项解析与数值校验：旋转坐标不变性、倒退/横滑检测、缺失状态排除、零权重输出精确回归、公交倒退不受惩罚，以及转向梯度/条件/KL。先通过这些检查再进行 GPU 对照。

第一阶段结果：所有车辆朝向开放后，种子 0 事件重新出现公交重叠，自车峰值朝向变化率约 1.50 rad/s，因此拒绝扩到三种子。追加两个预定对照：`ego_heading_probe` 只开放自车朝向；`ego_motion_probe` 再加入上述一致性组合项，二者只差 `--ego-motion-weight 100`。不改其余物理参数和预算。追加背景车辆朝向输出保持原锚点的数值测试。

上述对照完成后，正常组运动一致性改善，但事件组仍不安全。最后追加 `ego_curvature_probe`：仅新增 `--ego-curvature-weight 1000`，对 `|yaw_rate| <= 0.2 × XY速度` 的超限做软惩罚，避免静止原地转车头。0.2/m 为工程曲率上限，不声称完整自行车或转向执行器模型。补充静止旋转失败/半径 10 米圆弧通过的解析测试。此轮最多推进至该项的验收；失败时不继续扩参数搜索，也不提升默认采样。

曲率实验结果返回前补充明确的程序化门槛：逐例密集碰撞、道路中心/车框越界、加速度超限均不得超过对应 V2 基线；自车累计倒退≤0.2米、侧向速度 RMS≤0.25m/s、速度头残差 RMS≤0.5m/s、移动时车头方向误差≤15度、峰值朝向变化率≤0.6rad/s。属于工程质量门槛，不能替代安全证明；不设必须左转或最大化进展的目标。任一失败即拒绝推进三种子验证，并如实记录。
