# 当前baseline的问题与下一阶段方向

冻结日期：2026-10-30。本说明覆盖我们负责的Nexus条件轨迹生成分支及其3DGS下游接入。结论依据本地已保存的实验，不能当作原论文总体性能评测。

## 当前已经得到什么

链路为“指定待编辑车辆A的事件轨迹 → Nexus结合推理期引导生成其余车辆响应 → 独立几何/运动检查 → 3DGS视频”。后续车辆未来在主实验中自由，正常/事件配对保持历史、掩码、噪声及配置一致。我们增加了巡航、运动学、碰撞/道路约束和车道候选选择，没有重新训练Nexus权重。

- 033场景实现A切入、B减速、C跟驰减速。加强事件下，B轨迹替换诊断能引发C额外减速，提供条件生成器内的传播证据。
- 059场景实现A切入、B减速、C变道绕行；主三车检查通过，源轨迹C约4.1秒完整进入邻道，约5.3秒完全超过B。
- 外部车辆高斯资产可随轨迹插入新的121道路背景，已提供外部观察及B车四向同步渲染。道路适配后展示时序约4.0秒/5.2秒，必须与源059时序区分。

## 主要缺点及其依据

| 问题 | 当前证据 | 对项目的影响及优化方向 |
| --- | --- | --- |
| 运动和安全缺乏硬保证 | 早期开放朝向的开发探针虽改善转向/倒退，却增加完整车框重叠；多个后续案例仍有非主角车辆出道路 | 将动态参数化、车道合法性和安全筛选结合，验收全体参与者，保留失败，不能只优化主角画面 |
| 高级行为依赖新增显式模块 | 059变道版本使用保持车道/换道候选、空间模式先验及共同代价选择 | 目前应称为Nexus加行为搜索与轨迹优化；需要同条件消融，测量原模型与新增模块各自贡献 |
| 多车联动不等于严格因果链 | 059的B固定诊断整对未通过；正常B固定组与其他车辆出现14个重叠检查样本。A同时让出相邻车道，也可能影响C选择 | 同时控制B反应与邻道占用，保证整对诊断物理有效，再判断B→C的贡献 |
| 泛化证据不足 | 059高级变道主要为单场景、seed0；跨场景015/018虽能减速，强化批次C最大位置差仅约0.084/0.014米 | 按历史几何预选强交互，冻结参数，使用独立场景和多种子，分别统计有效输入率、主角响应及全场景验收 |
| 事件输入可能先天不可行 | 050给定A与不可编辑记录背景在4.9—6.2秒有14个重叠采样点；060地图参考到末端后夹停，不能构成有效8秒事件 | 在采样前检查A与地图、固定交通、速度/加速度及参考路径长度是否相容，区分输入冲突与模型响应失败 |
| 未来条件带来提前响应 | A整段未来从采样开始已知，部分实验还使用记录背景和未来存在掩码 | 适用于离线条件场景生成；真实“观察后反应时间”需要仅过去可见、滚动更新的闭环协议重新评估 |
| 全场景通过率与主三车表现有差距 | 059主三车通过，但其余合格车辆仍有正常/事件55/64个车身出道路检查样本 | 下游导出必须声明验收范围；三车样例不能作为全场景安全证明 |
| 3DGS新视角覆盖不足 | 121外部视角树木/远景偏软；B侧后方出现明显模糊、破碎及浮点，背景训练主要使用前向和侧前向图像 | 补充相应视角图像监督并检查可观测覆盖、道路几何与遮挡；资产插入只能提供车辆外观，不能补足未重建背景 |
| 资产与新道路适配仍有近似 | 059运动通过成对车道曲线坐标迁移到121；车辆高度用点云平面和不超过约14厘米的重建深度校准，阴影为薄高斯近似 | 保存原始运动与派生运动的来源和检查；进一步使用道路曲面/接触约束和一致光照验证贴地效果 |

## 下一阶段优先顺序

1. 冻结现有开发结果和输入协议，整理可复现入口、失败案例及独立验收，先完成本次私有代码交付。
2. 改进事件编译：先验证输入可行，再根据历史几何和风险选择真正会形成强三车交互的场景。
3. 使用冻结配置开展独立场景、多种子和组件消融，分别报告主三车与完整交通表现。
4. 补齐B反应/邻道占用的有效配对诊断，区分可见联动、条件传播和严格因果结论。
5. 独立改进3DGS环视背景覆盖和资产落地效果，再进行多视角画质验收。
