# multiagent

Nexus traffic scene generation, local interaction guidance, and 3D Gaussian Splatting integration.

- [Nexus source and documentation](Nexus/README.md)
- [Upstream installation guide](Nexus/docs/install.md)
- [Scene generation reproduction notes](Nexus/docs/reproduction_scene_gen.md)

The root directory contains the reproduction scripts and dependency version records. Set up the software environment, datasets, and model checkpoints before running the demos. Some historical experiment scripts use paths from the original environment.
